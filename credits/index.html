引用声明

按照课程「真实」底线的要求，把本网站用到的框架、工具和别人的帮助如实列在这里。

框架与模板

  • 本网站基于开源框架 Next.js（React）和 Tailwind CSS 搭建，两者均免费开源
  • 网站初始结构由 Next.js 官方脚手架 create-next-app 生成，之后逐步修改成现在的样子

AI 辅助

  • 开发前期使用 Claude Code，后期主要使用 DeepSeek Harness（AI 编程助手）：生成和修改代码结构、排查报错、整理页面内容
  • AI 草拟的内容由我逐条核对和修改；AI 参与较多的部分已记录在「过程证据」页的提示词记录里
  • 三个项目中的 AI 使用情况也已分别写在「项目成果」页的技术说明里（秒哒平台、AI 提示词思路、Trae 辅助写代码）

同伴与老师帮助

  • 本网站由我本人独立完成（在 AI 编程助手辅助下），没有请教过同学或老师

素材与部署平台

  • 网站文字为本人撰写（AI 草拟的部分已标注并核对）；目前未使用他人图片素材，以后补充的截图均为我自己项目的截图
  • 部署平台：Netlify（主网址）、Vercel（备用网址），均为免费套餐

隐私与安全

  • 网站不含 API 密钥、密码等敏感信息；本地凭证文件已加入 .gitignore，不会上传到 GitHub
  • 页脚的联系邮箱为本人自愿公开，用于课程交流
